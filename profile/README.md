# HarLin Consulting Pty Ltd

HarLin builds practical, bounded digital tools that turn operational evidence
into clear, reviewable artefacts.

## Featured public tool

### Repository Assurance Snapshot

A read-only GitHub Action and Python CLI that generates a human-readable
`ASSURANCE.md`, machine-readable `assurance.json`, and SHA-256 evidence
manifest for one public repository revision.

- [Use the free Action or CLI](https://github.com/HarLin-Consulting-Pty-Ltd/repository-assurance-snapshot)
- [Buy a human-reviewed public-repository snapshot](https://msharlincreations.gumroad.com/l/public-repository-assurance-snapshot)

The collector requests no token or private access, does not clone or execute
repository code, and does not claim to provide an audit, certification,
penetration test, legal licence opinion or security warranty.
