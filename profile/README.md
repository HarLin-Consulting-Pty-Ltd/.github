# HarLin Consulting Pty Ltd

HarLin Consulting helps exploration leaders make consequential decisions with better evidence, independent challenge and senior geological judgement.

## How HarLin helps

- **Exploration Decision Review** — clarify the decision, knowns and unknowns, and the next highest-value evidence or test.
- **Tenure and Portfolio Value Advancement** — turn fragmented or underused evidence into clearer options and more durable project value.
- **Programme and Target Assurance** — independently challenge the geological model, proposed tests and decision gates.
- **Technical Due Diligence and Independent Assessment** — source-grounded review with explicit materiality, limitations and professional accountability.
- **Fractional Exploration Decision Partner** — recurring senior judgement across portfolio, programme, evidence and assurance decisions.

Our work asks a practical question: **which evidence could change this decision?** Digital tools, structured evidence and automation support that work; they do not replace geological judgement or accountability.

## Public tools

### [Repository Assurance Snapshot](https://github.com/HarLin-Consulting-Pty-Ltd/repository-assurance-snapshot)

A read-only GitHub Action and Python CLI that creates a human-readable `ASSURANCE.md`, machine-readable `assurance.json`, and a SHA-256 evidence manifest for one public repository revision.

- [Use the free Action or CLI](https://github.com/HarLin-Consulting-Pty-Ltd/repository-assurance-snapshot)
- [Review the current release and provenance](https://github.com/HarLin-Consulting-Pty-Ltd/repository-assurance-snapshot/releases/latest)
- [Open the buyer-facing assurance page](https://harlin-consulting-pty-ltd.github.io/repository-assurance-snapshot/)
- [Commission a human-reviewed public-repository snapshot](https://msharlincreations.gumroad.com/l/public-repository-assurance-snapshot?utm_source=github&utm_medium=organic&utm_campaign=repository_assurance_v1&utm_content=org_profile)
- [Report an issue or request support](https://github.com/HarLin-Consulting-Pty-Ltd/repository-assurance-snapshot/issues)

The collector requests no token or private access, does not clone or execute repository code, and does not claim to provide an audit, certification, penetration test, legal licence opinion or security warranty. The repository records its licence, release history, tests, publishing controls and observed limitations.
